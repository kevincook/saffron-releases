# Saffron

Saffron is a personal recipe manager for macOS and Windows: keep your recipe library, import recipes from a web page, scale servings, build a grocery list, and cook step by step.

This repository holds Saffron's downloads and website only. The source code is private.

## Download

- **macOS** (12 or later, Apple Silicon and Intel, signed and notarized): [Saffron-mac.zip](https://github.com/kevincook/saffron-releases/releases/latest/download/Saffron-mac.zip)
- **Windows** (Windows 11 x64, unsigned preview): [Saffron-windows-setup.exe](https://github.com/kevincook/saffron-releases/releases/latest/download/Saffron-windows-setup.exe)

All versions: [Releases](https://github.com/kevincook/saffron-releases/releases)

### Windows preview note

The Windows installer isn't code-signed yet, so Windows shows "Windows protected your PC". Click **More info**, then **Run anyway**.
